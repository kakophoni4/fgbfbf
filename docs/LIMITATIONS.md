# Первая версия

- Не запускалась и не тестировалась локально по указанию заказчика. Серверные проверки обязательны.
- Один процесс Uvicorn, одна реплика, один SQLite volume. Не повышать workers/replicas:
  локальные блокировки, очередь и обработка перезапуска рассчитаны на один процесс.
- Одна генерация одновременно, до восьми принятых запросов суммарно. Это не production-бенчмарк.
- История и снимок контекста хранятся в базе. Автоматического срока удаления, шифрования базы
  на уровне приложения и автоматического обезличивания пока нет. Не вносить реальные персональные
  данные до согласования хранения и доступа. Удаление примера не удаляет исходный запрос.
- Предусмотрен лимит тела и консервативный бюджет по символам. Это не точный токенизатор T-Pro;
  истории могут отклоняться раньше реального предела. Передавайте компактную историю.
- Не поддерживаются изображения, голос, файлы, RAG, инструменты модели и автоматическая отправка.
- Нет персональных пользователей и мультиарендности: CRM выступает доверенным клиентом.
- Базовый URL меняет только администратор. Приватные адреса нужны по назначению сервиса;
  это НЕ изолированный сетевой прокси. Разрешайте исходящий трафик только к нужному Ollama-хосту
  на уровне сети. Токен шлюза задаётся при развёртывании и не возвращается API.
- Структурированный формат ответа требует поддержки Ollama и проверки на реальной модели.
  Промпт не даёт математической гарантии поведения; отправкой и передачей управляет CRM.
- После сбоя незавершённая генерация не возобновляется. Нужен новый request_id.
- Версии промптов и моделей — разные сущности. Первая версия управляет промптами;
  модель выбирается из уже установленных в Ollama. Скачивание моделей и обучение не реализованы.
- Зависимости ограничены диапазонами, но полного lock-файла ещё нет. После серверной приёмки
  следует зафиксировать проверенные версии перед повторяемыми production-сборками.
