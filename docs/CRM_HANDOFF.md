# Задание команде разработки CRM

Нужно реализовать интеграцию существующей CRM с уже развёрнутым отдельным ИИ-сервисом.
Полное обязательное ТЗ: [CRM_SPEC.md](CRM_SPEC.md), версия 1.1.

## Что уже готово

ИИ API и Ollama находятся на отдельном сервере 45.74.3.230. CRM — 146.19.125.32.
WireGuard между ними работает. Адрес API для CRM: **http://10.77.77.1:8088**.
GET /health успешно проверен с CRM-хоста и из crm-staging-api.
Повторно настраивать сеть или размещать Ollama внутри CRM не нужно.

Ключи передаются отдельно файлом crm-ai-connection.env. Заказчику дана команда создания
этого файла по пути /root/crm-ai-connection.env на ИИ-сервере. Получить файл безопасно и
подключить его значения в окружение api и worker CRM; не отправлять ключи во frontend и Git.
Имена переменных: AI_SERVICE_BASE_URL, AI_SERVICE_REPLY_KEY, AI_SERVICE_ADMIN_KEY.
Проверить авторизованные /v1/capabilities и /v1/connection из обоих контейнеров.

## Что реализовать в CRM

1. Backend-клиент ИИ API с двумя ключами, обработкой ошибок, 202/polling и повторами по request_id.
2. Админский раздел: подключение, версии промпта, каталог, тестовый чат, примеры, датасеты,
   обучение, версии моделей и аудит. Только admin; проверка также на backend.
3. В чатах: включение/выключение ИИ, передача закреплённому менеджеру, подстраховка после
   15 минут без ответа человека. Таймеры и отправка сообщений остаются в CRM worker.
4. Защита от двойной отправки и устаревших ответов при сообщении менеджера/клиента или смене режима.
5. Исправление ответов и одобрение примеров. Загрузка готовых JSONL/GZ и подготовка сырой
   CRM-выгрузки с предпросмотром, выбором хороших ответов и обезличиванием.
6. Реальное обучение через API: создание задачи, логи, отмена, тест кандидата, отдельное
   одобрение/активация и откат. Смена промпта НЕ является обучением.
7. Персональный аудит, сохранение request_id/job_id/activation_id и серверная приёмка.

## Что ещё не проверено

Генерация через API и полный цикл обучения не прошли приёмку. GPU-worker уже online,
но обучение ограничено реальными ресурсами: на 16 GB карте T-Pro-профиль не допускается;
T-Lite требует минимум 12 GiB свободной VRAM. Не подменять модель автоматически и не
останавливать другие процессы ради обучения. Текущий промпт должен задать администратор.
