# FGBFBF — отдельный ИИ API для CRM

FastAPI-сервис между backend CRM и Ollama. CRM передаёт историю сообщений, сервис добавляет
активный промпт и каталог, возвращает структурированный ответ. CRM и её база не изменяются.
Сервис не отправляет сообщения клиентам, не управляет менеджерами и не запускает обучение.

## Состояние

Первая реализация, подготовленная к проверке на сервере. По просьбе заказчика локальный запуск,
сборка контейнера и тестирование не выполнялись. Успешная работа с реальной T-Pro ещё не подтверждена.

## Возможности

- Два ключа: генерация/статус и административные операции.
- Адрес Ollama, модель и параметры меняются по API.
- Неизменяемые версии промпта, активация и откат.
- Редактируемый каталог с номером версии.
- Генерация, тест произвольной версии промпта, опрос состояния долгого запроса.
- Идемпотентность request_id: успешный повтор возвращает сохранённый ответ.
- Одобренные примеры из успешных запросов: исправление, отзыв одобрения при правке, экспорт JSONL.
- Аудит изменений без текстов диалогов и ключей в журнале.
- Постоянная SQLite-база в Docker volume, одна реплика/один процесс API.
- Обучение явно недоступно: POST /v1/training/jobs возвращает 501 и ничего не запускает.
